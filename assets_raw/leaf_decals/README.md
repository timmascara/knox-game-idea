# leaf_decals — not a model, so `npm run assets` skips it

`pavements_vol_01_leaves_2k.zip` is nine sets of fallen-leaf cut-outs and one
of petals (diffuse + alpha + normal + bump + displacement each, 2K), from a
pavement texture series. It contains **no pavement surface** — the owner
downloaded it thinking it was the ground texture. It is not; it is the
scatter that goes on top of one.

Use: textures on ground-hugging quads scattered around the park's paths and
under the trees. Leave the zip as-is; unpack at build time like everything
else in `assets_raw/`.
